# Usability and reliability audit — 21 September 2026

Scope: inspect the current three-level game against the actual non-reader, animal-led direction; trace story, navigation, saved state, parent controls, language and offline behavior. This is an assistant review and browser test, not a child usability study. No previous level or approved character/classroom asset is removed.

| Finding | Change | Verification |
|---|---|---|
| I18: Repeated “rest” distractor made waking, travel and meals into arbitrary right/wrong questions | Waking/travel have one invitation. Brushing/food/sleep use distinct relevant objects. Alternate choices receive specific recorded help; no progress penalty. Correct choices do not always occupy the left tile. | Day/audit browser journeys; content coverage; English/Hindi retry queue assertions |
| I19: Bed choice led to sleeping on floor; toothbrush floated below mouth; travel began at destination; morning/bedtime thumbnails identical | Matching morning/night bed views, sleeping sprite on mattress, toothbrush placed at mouth only after selection, travel starts in source setting and transitions to destination; sun/moon chapter badges | Phone and desktop composites, both heroes' brushing, bedtime prompt/outcome, travel state and offline image decode |
| I20: Choosing a chapter silently overwrote an unfinished checkpoint | Schema 3 stores per-animal, per-chapter bookmarks. Cards resume unfinished chapters and say Play again after completion. Main button names saved beat and says Start on first play. | Reducer test including counted outcome, browser switching/reload, actual v10→v11 migration |
| I21: Reloading a chooser reopened a scene; pending audio startup could bring it back after navigation | Save coarse navigation view; cancel pending entry before it creates a session or renders | Offline reload; delayed AudioContext startup test leaves Levels and no hidden session |
| I22: Parent guide described only old action mode, Activity control had no useful visible effect, story progress absent | Explain three levels, remove redundant Activity selector (Levels remains), show per-animal/chapter practice and independent parent observations; animal-group selector clearly applies to names/letters | Parent settings observation persistence and return-to-level checks |
| I23: Backup quota failure reset a valid loaded save | Separate loading from best-effort backup, retain loaded data on backup failure, keep versioned migration backups; preserve malformed input before recovery writes | Unit quota/corrupt-save/future-schema cases, upgrade regression |
| I24: Returning from actions to names could retain an animal outside the chosen group | Reconcile valid targets in both directions without renewing deadline/turns | Names→actions and actions→names browser tests |

Product review: three equally visible levels retained. Existing animated grass/carrot, walk/sleep and school practice remain. The same protagonist travels home→school→home. The original home image is still used for brushing/breakfast, and approved lake/character files are unchanged. Morning greeting is addressed to the co-playing parent through the existing bridge; no new in-scene family character has been built.

Not covered by a technical pass: whether the child recognises a picture without help, listens comfortably, understands a sentence, uses it away from the app, or accepts stopping. Physical installed iPhone/Android testing and human pronunciation review remain open. Making bed, dressing, packing, tidying and richer friend interactions are still content roadmap items, not shipped features. The current sprites remain a simple two-pose animation style; this audit does not claim full character animation.

Evidence and release status: RELEASES.md and CURRENT_STATE.md. Preserve failed first-run evidence; do not equate test count with absence of every UX flaw.
